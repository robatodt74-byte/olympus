# 外部サービスの接続確認

適用: 接続の棚卸し・問題調査・新しい操作先の確認。通常のツール選択だけなら読まない。

## 接続と権限の確認

| 機能 | 用途 | 実行前に確認 |
|---|---|---|
| Slack | 依頼・変更・返信待ちの読取、許可された投稿 | ワークスペース、チャンネル、対象期間、送信許可 |
| Gmail | メールの検索・読取、依頼された下書き・送信 | アカウント、スレッド、宛先、送信許可 |
| Google Calendar | 予定・空き時間の確認、依頼された登録 | カレンダー、タイムゾーン、参加者、重複 |
| GitHub / Linear | 指定プロジェクトの課題・PR | repo/team/project、操作範囲、対象ID |
| Google Drive / 文書ツール | Docs・Sheets・Slidesの編集 | ファイル・シート・範囲、共有範囲、更新結果 |

掲載、導入、設定の有効化、ツールの公開、接続・認証、実操作成功は別状態として確認する。古い接続一覧は現在の成功証拠にしない。秘密値を表示・転記しない。
